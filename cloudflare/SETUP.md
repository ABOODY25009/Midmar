# إعداد مِضمار 2.4.0

## موارد النسخة الجديدة
- Worker: `midmar-v2-dev`
- قاعدة البيانات: `midmar-dev`
- اسم ربط D1: `DB`
- اسم ربط Workers AI: `AI` (لم يعد مسار استخراج الأسئلة يستخدمه)
- مصادقة Google: `GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET` كـ Secrets.

## الحسابات
- ينشئ المستخدم حسابًا بالبريد الإلكتروني وكلمة مرور من 8 أحرف فأكثر.
- يختار الدور عند إنشاء الحساب فقط: `teacher` أو `student`.
- يقرأ الموقع الدور المحفوظ في قاعدة البيانات عند كل تسجيل دخول، ويعرض لوحة المعلم أو مساحة الطالب.
- يحتفظ المستخدم بنفس الدور عند تسجيل الدخول لاحقًا.
- يمكن أيضًا إنشاء/ربط حساب Google؛ عند تسجيل حساب Google جديد يحدد الرابط الدور المراد إنشاؤه.
- حساب البريد وكلمة المرور يبدأ غير موثّق. يجب ربطه بحساب Google يحمل البريد نفسه من الإعدادات للتحقق من ملكية البريد.
- حسابات Google الحالية تم اعتبارها موثقة عند تطبيق ترقية قاعدة البيانات.

## الطلاب ومجموعات الوصول
- الطالب ينشئ حسابًا بدور `student` باسمه وبريده.
- يوثّق البريد من خلال Google من صفحة الطالب أو الإعدادات.
- ينشئ المعلم مجموعة وصول ويضع البريد الإلكتروني لكل طالب مرة واحدة.
- يسمح النظام فقط بإضافة حسابات الطلاب المسجلة والموثقة.
- عند إنشاء مسابقة بمشاركة فردية، يختار المعلم مجموعة أو أكثر بدل إعادة إدخال قائمة الطلاب.
- قبل الانضمام، يتحقق Worker من جلسة الطالب ومن وجوده ضمن إحدى مجموعات الوصول المربوطة بالمسابقة.
- يحصل الطالب على معرّف ثابت بالشكل `STD-000001`، وتُحفظ مشاركاته مرتبطة بمعرفه.

## الذكاء الاصطناعي ومفتاح OpenAI
مسار قراءة أوراق الأسئلة يستخدم OpenAI Chat Completions مع نموذج `gpt-4o-mini`.

أضف مفتاحك في Cloudflare كـ Secret:
1. افتح Worker `midmar-v2-dev` من صفحة Workers & Pages.
2. افتح Settings ثم Variables and Secrets.
3. اضغط Add واختر Secret.
4. الاسم: `OPENAI_API_KEY`.
5. القيمة: مفتاح OpenAI الخاص بك.
6. اضغط Save and Deploy.

لا تضع المفتاح في GitHub أو في كود الواجهة أو في `wrangler.jsonc`. يتحقق الموقع من حالة المفتاح عبر `GET /api/ai/status` ولا يعرض قيمته مطلقًا.

## إنشاء المسابقة
صفحة إنشاء المسابقة تستخدم زر إجراء أساسيًا واحدًا؛ يتحول من «التالي» إلى «إنشاء المسابقة» في الخطوة الأخيرة. يجب اختيار مجموعة وصول واحدة على الأقل عند اختيار مشاركة الطلاب.

## ملفات التنفيذ
- `cloudflare/worker.js`: API والمصادقة والتحقق من أدوار الحسابات.
- `cloudflare/assets.js`: ملفات الواجهة المعبأة داخل Worker، بالإضافة إلى شعار WebP.
- `cloudflare/migrations/0002_accounts_and_student_groups.sql`: ترقية الحسابات والطلاب ومجموعات الوصول.
