# مِضمار – منصة مسابقات الفصل

## التشغيل على Windows 11
1. ثبّتي Node.js (الإصدار 22.13 أو أحدث، ويعمل مع 24 و25) من nodejs.org. لا حاجة لـ Visual Studio ولا Python.
2. افتحي PowerShell داخل مجلد المشروع ونفّذي:
   `npm install` ثم `npm start`
3. افتحي http://localhost:3000 — أدخلي اسم المعلمة ورمز الدخول الموحد `1234`.
4. البيانات تُحفظ في `data/midmar.db` وتبقى بعد إعادة التشغيل. انسخي هذا الملف للنسخ الاحتياطي.

## الاستخدام في الفصل
1. «مسابقة جديدة» ← أضيفي الأسئلة (اسحبي ⠿ للترتيب) ← «حفظ».
2. من «المسابقات» اضغطي «ابدأ المسابقة» لفتح شاشة العرض ورمز QR.
3. شاشة «ابدأ المسابقة» تعرض رمز QR قبل أول إجابة مكتملة، ثم تصغّره على الجانب وتعرض ترتيب الفرق المكتملة مباشرة. اضغطي «ملء الشاشة» عند الحاجة.
4. من صفحة النتائج: إخفاء/إظهار النتائج، التصدير CSV، حذف مجموعة.
ملاحظة: بعد بدء أي مجموعة باللعب تُقفل أسئلة المسابقة من التعديل حفاظًا على صحة النتائج؛ انسخي المسابقة لتعديلها.

## على شبكة الفصل (بدون إنترنت عام)
شغّلي الخادم على جهاز المعلمة، وأرسلي للطالبات `http://عنوان-الجهاز:3000/j/الرمز` (عنوان IP عبر `ipconfig`) وتأكدي أن Windows Firewall يسمح بالمنفذ 3000.

## النشر على الإنترنت
المشروع جاهز عبر Docker (`Dockerfile`) وملف `render.yaml` لمنصة Render (أو Railway/Fly.io). يلزم قرص دائم مركّب على `/data` لحفظ قاعدة البيانات، واستضافة تدعم WebSocket. بعد النشر تعمل الروابط وQR تلقائيًا بعنوان موقعك (HTTPS).
