# مِضمار – منصة مسابقات الفصل

## التشغيل على Windows 11
1. ثبّتي Node.js (الإصدار 22.13 أو أحدث، ويعمل مع 24 و25) من nodejs.org. لا حاجة لـ Visual Studio ولا Python.
2. افتحي PowerShell داخل مجلد المشروع ونفّذي:
   `npm install` ثم `npm start`
3. افتحي http://localhost:3000 وادخلي باسم المعلمة والرمز الموحد `1234` (لا حساب ولا كلمة مرور؛ الاسم هو ما يميّز المعلمات، ويمكن تغيير الرمز بالمتغير `TEACHER_CODE`).
4. البيانات تُحفظ في `data/midmar.db` وتبقى بعد إعادة التشغيل. انسخي هذا الملف للنسخ الاحتياطي.

## الاستخدام في الفصل
1. «مسابقة جديدة» ← أضيفي الأسئلة (اسحبي ⠿ للترتيب) ← «حفظ».
2. من «المسابقات» اضغطي **ابدأ المسابقة**: تُفتح شاشة العرض فيها QR كبير ورابط للنسخ وأسماء الفرق المنضمة لحظيًا (اضغطي «ملء الشاشة» للبروجكتور). لا انضمام قبل الضغط على الزر.
3. عندما ينهي أول فريق يصغر QR إلى الجانب (ويبقى الانضمام متاحًا) وتظهر «اكتمل الفريق الأول!» مع اسمه وزمنه، ثم يظهر الترتيب كاملًا عند انتهاء الجميع.
4. من صفحة النتائج: فتح/إيقاف الانضمام، إخفاء/إظهار النتائج، التصدير CSV، حذف مجموعة.
ملاحظة: بعد بدء أي مجموعة باللعب تُقفل أسئلة المسابقة من التعديل حفاظًا على صحة النتائج؛ انسخي المسابقة لتعديلها.

## على شبكة الفصل (بدون إنترنت عام)
شغّلي الخادم على جهاز المعلمة، وأرسلي للطالبات `http://عنوان-الجهاز:3000/j/الرمز` (عنوان IP عبر `ipconfig`) وتأكدي أن Windows Firewall يسمح بالمنفذ 3000.

## النشر على الإنترنت
المشروع جاهز عبر Docker (`Dockerfile`) وملف `render.yaml` لمنصة Render (أو Railway/Fly.io). يلزم قرص دائم مركّب على `/data` لحفظ قاعدة البيانات، واستضافة تدعم WebSocket. بعد النشر تعمل الروابط وQR تلقائيًا بعنوان موقعك (HTTPS).

## الاختبار
`npm test` يشغّل 36 اختبار تكامل (دخول متزامن لـ5 مجموعات، التصحيح، التحديث المباشر، الاستمرارية...).

## نشر كامل على الإنترنت (ثلاث طرق)
**أهم قاعدتين:** (1) تشغيل نسخة واحدة فقط من الخادم لأن القاعدة SQLite. (2) ربط قرص دائم بالمسار `/data` وإلا تضيع البيانات عند كل نشر.

**أ) Render (الأسهل):** ارفعي المشروع على GitHub ← Render > New > Blueprint ← اختاري المستودع (يقرأ render.yaml). الخطة المدفوعة مطلوبة لأن القرص الدائم غير متاح في المجانية. تحصلين على رابط https مباشرة.

**ب) Fly.io:** `fly launch --no-deploy` ثم `fly volumes create data --size 1` ثم `fly deploy` (الملف fly.toml جاهز، غيّري اسم التطبيق).

**ج) خادم خاص VPS (أرخص وأكثر تحكمًا):** على Ubuntu مع Docker: ارفعي المشروع، وجّهي نطاقك إلى عنوان الخادم، عدّلي Caddyfile باسم النطاق، ثم `docker compose up -d --build`. يصدر Caddy شهادة HTTPS تلقائيًا.

النسخ الاحتياطي: انسخي ملف `midmar.db` دوريًا.
